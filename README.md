## AI Beginner Quiz Library

The quiz workspace supports 48 job roles across technology, administration,
skilled trades, healthcare, hospitality, retail, and operations. A new
Beginner quiz can be generated by MiniMax in one server-side batch, saved to
MongoDB, and graded with one AI-assisted batch. Multiple-choice answers are
also checked against the stored answer key, and answer-key grading remains
available when the AI provider is unavailable.

The controlled seed target is 30 Beginner questions per role (1,440 total).
The application stops automatically growing a role's AI question bank at 40
questions, keeping the full catalog at no more than 1,920 Beginner questions.

Required `.env.local` values:

```bash
MINIMAX_API_KEY=your-key
MINIMAX_BASE_URL=https://api.minimax.io/v1
MINIMAX_MODEL=MiniMax-M2.7
MONGODB_URI=your-mongodb-connection
MONGODB_DB=career_forge
```

Seed the complete 1,440-question Beginner library:

```bash
npm run seed:quiz:ai
```

The seeder resumes from the questions already stored, retries temporary AI
provider failures up to five times per batch, and continues with other roles if
one role still fails. You can safely run the same command again to fill any
remaining roles without deleting or duplicating completed questions.

Optional retry controls:

```powershell
$env:QUIZ_AI_BATCH_RETRIES='7'
$env:QUIZ_AI_RETRY_DELAY_MS='5000'
npm run seed:quiz:ai
```

Seed or repair one role only:

```powershell
$env:QUIZ_AI_ROLE='Automotive Mechanic'
npm run seed:quiz:ai
```

The seeding command makes paid provider requests and writes to the configured
MongoDB database. Run it deliberately and monitor provider usage.
