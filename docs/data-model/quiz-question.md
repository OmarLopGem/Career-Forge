# `quiz_questions`

Quiz question bank for the orientation quiz. Each question is tied to a `jobType` (job role) and a `difficulty` (Beginner / Intermediate / Advanced).

**MongoDB collection:** `quiz_questions`
**Mongoose model:** `lib/db/models/quiz-question.js`
**Exported function:** `getQuizQuestionModel()`

## Document structure

```json
{
  "_id": "ObjectId",
  "jobType": "string",
  "type": "'multiple_choice' | 'true_false' | 'short_answer'",
  "difficulty": "'Beginner' | 'Intermediate' | 'Advanced'",
  "source": "'manual' | 'ai' (default 'manual')",
  "question": "string",
  "options": "string[] | { correct: string, distractors: string[] }",
  "answer": "string | string[]",
  "marks": "number",
  "createdAt": "string ISO-8601",
  "updatedAt": "string ISO-8601"
}
```

## Fields

| Field | Type | Notes |
|---|---|---|
| `jobType` | string | Role identifier (e.g. `'Software Engineer'`, `'Nurse'`). Used to filter the bank. |
| `type` | string | Question type. Today only `multiple_choice` is used end-to-end. |
| `difficulty` | string | Level. Defines pool and scoring. |
| `source` | string | `'manual'` (initial seed) or `'ai'` (generated by the AI seeder). |
| `question` | string | Statement. Unique per `jobType` (unique index). |
| `options` | mixed | Array of strings (shown to the user) or `{ correct, distractors }` structure. |
| `answer` | string \| string[] | Answer key for the answer-key grader. |
| `marks` | number | Question weight. |

## Bank size controls

- **Target per role:** 30 Beginner questions.
- **Absolute cap:** 40 Beginner questions per role.
- **Total target catalog:** 1,440 Beginner questions (48 roles × 30).
- **Absolute catalog cap:** 1,920 (48 × 40).

The AI seeder (`npm run seed:quiz:ai`) respects these limits and can be re-run idempotently.

## Indexes

- `{ jobType: 1 }` (`quiz_questions_job_type`).
- `{ jobType: 1, question: 1 }` unique (`quiz_questions_job_type_question`).

## Relationships

- **N:M → `quiz_attempts`** via `quiz_attempts.questionIds: ObjectId[]`.

There is no formal FK: when an attempt is closed, `questionIds` is resolved and the text is frozen in `quiz_results`.
